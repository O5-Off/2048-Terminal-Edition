A Python implementation of the classic 2048 puzzle game.

The classic 2048 puzzle game where you can play on the terminal! The code contains 320 lines in total. All available controls appear on the terminal each time while you are playing. When the script itself is well orginized and thoroughly commented.

To start playing, the pygame should be installed. If you have not completed it yet, then write the command "pip install pygame" to install pygame based on your python version. Once you gave finished, open the file in VS Code and hit the run button.
